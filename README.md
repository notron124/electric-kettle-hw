# Эмулятор чайника.
## Задача в курсе Си++/Qt

Прочти ПОЛНОСТЬЮ, потом делай!

Вам предоставляется исходный код симулятора работы электрического чайника.

Симулятор имеет графический интерфейс с отображением текущих показаний всех доступных
устройству датчиков и графиками показаний датчиков температуры воды и температуры пара,
кнопками запуска и остановки симуляции, а так же чекбоксами для управления нагревом 
вручную, либо включения автоматического управления из вашей программы, а так же генерации 
случайных событий (пользования чайником).

Проект собирается в QtCreator вместе с библиотекой Qt версии 5 (уточнение версии не имеет 
значения).

В данном коде есть класс KettleControllerImpl, который представляет собой класс управления 
чайником. Вам доступны методы интерфейса KettleControllerBase для контроля состояния и 
управления чайником. Остальные условия описаны в kettlecontrollerimpl.cpp и другой 
документации в коде.
 
Принимаются предложения по улучшению общего кода и Feature-request-ы с вашей реализацией.
